# SFEK College — Инструкция по запуску с флешки

## Что нужно установить на компьютере (один раз)

### 1. Node.js 18+
- Скачайте: https://nodejs.org (кнопка LTS)
- Установите, всё по умолчанию, нажимайте "Next"
- После установки перезагрузите компьютер

### 2. Docker Desktop
- Скачайте: https://www.docker.com/products/docker-desktop/
- Установите, всё по умолчанию
- **ВАЖНО:** После установки запустите Docker Desktop и подождите пока он полностью запустится (иконка кита в трее станет зелёной)

---

## Запуск проекта

### Способ 1: Автоматический (рекомендуется)

1. Скопируйте папку `sfek-college-schedule` с флешки на рабочий стол
2. Откройте папку `sfek-college-schedule`
3. Дважды кликните на файл **`START.bat`**
4. Подождите 1-2 минуты — браузер откроется автоматически
5. Готово! Сайт работает на http://localhost:5173

### Способ 2: Ручной (если автоматический не работает)

Откройте **Командную строку** (Win+R → cmd → Enter):

```bash
# 1. Перейдите в папку проекта (замените путь на ваш)
cd C:\Users\ВашеИмя\Desktop\sfek-college-schedule

# 2. Запустите PostgreSQL
docker run -d --name sfek-postgres -e POSTGRES_USER=sfek_user -e POSTGRES_PASSWORD=sfek_password -e POSTGRES_DB=sfek_schedule -p 5432:5432 postgres:15-alpine

# 3. Подождите 5 секунд, затем:
cd backend
npm install
npx prisma migrate deploy
npx tsx prisma/seed.ts
npm run dev

# 4. Откройте ВТОРОЕ окно командной строки:
cd C:\Users\ВашеИмя\Desktop\sfek-college-schedule\frontend
npm install
npm run dev

# 5. Откройте браузер: http://localhost:5173
```

## Что показать на предзащите

### 1. Вход в систему (1 мин)
- Откройте сайт → покажите страницу входа
- Войдите как **Администратор** (admin@sfek.edu.kz)

### 2. Панель администратора (2 мин)
- Дашборд — статистика: студенты, учителя, предметы, аудитории
- Графики — сабақтар по дням, по типам (лекция/практика/лабораторная)

### 3. Расписание (2 мин)
- Недельный вид — полная сетка расписания
- Дневной вид — переключите на "День"
- Фильтр по группам — выберите конкретную группу

### 4. Управление данными (2 мин)
- Откройте "Оқытушылар/Учителя" — покажите карточки 8 учителей
- Покажите форму создания нового учителя
- Откройте "Студенттер/Студенты", "Пәндер/Предметы"

### 5. Мультиязычность (1 мин)
- Переключите язык: Қазақша → Русский → English
- Покажите что ВСЕ надписи меняются

### 6. Тёмная тема (30 сек)
- Нажмите на иконку луны → тёмная тема
- Нажмите на солнце → светлая тема

### 7. Ролевой доступ (1 мин)
- Выйдите из админа
- Войдите как **Студент** (student1@sfek.edu.kz) — Бекжан Акылбеков
- Покажите что студент видит только: Расписание, Уведомления, Настройки
- Покажите расписание своей группы

### 8. Код и архитектура (2 мин)
- Откройте GitHub: https://github.com/Miromo-stack/sfek-college-schedule
- Покажите структуру: backend/, frontend/, docker-compose.yml
- Упомяните технологии: React, TypeScript, Node.js, PostgreSQL, Prisma

## Возможные проблемы

**"Docker не запущен"**
→ Запустите Docker Desktop и подождите 1-2 минуты

**"Порт 5432 занят"**
→ Выполните: `docker stop sfek-postgres && docker rm sfek-postgres`
→ Затем запустите снова

**"npm не найден"**
→ Установите Node.js и перезагрузите компьютер

**Страница не открывается**
→ Подождите 30 секунд, серверы запускаются
→ Попробуйте http://localhost:5173 вручную
