## ПЕРЕД ПРЕДЗАЩИТОЙ (сделайте дома заранее!)

### Шаг 1: Установите программы на компьютер
1. **Node.js 18+** → https://nodejs.org (нажмите кнопку "LTS", установите, всё "Next")
2. **Docker Desktop** → https://docker.com/products/docker-desktop (установите, всё по умолчанию)
3. После установки **перезагрузите компьютер**

### Шаг 2: Проверьте что всё работает (тестовый запуск)
1. Скопируйте папку `sfek-college-schedule` с флешки на Рабочий стол
2. Запустите **Docker Desktop** → подождите пока иконка кита в трее станет зелёной (1-2 мин)
3. Дважды кликните **`ЗАПУСК_WINDOWS.bat`**
4. Подождите 1-2 минуты → браузер откроется автоматически
5. Войдите: **admin@sfek.edu.kz** / **Password123!**
6. Если всё загрузилось — вы готовы!

### Шаг 3: Перед выходом из дома
- Убедитесь что Docker Desktop **включён** на ноутбуке
- Папка проекта на Рабочем столе
- `node_modules` уже скачаны (первый запуск скачает их автоматически)

## ВОЗМОЖНЫЕ ВОПРОСЫ И ОТВЕТЫ

### «Почему вы выбрали именно эти технологии?»
> «React — самый популярный frontend-фреймворк, TypeScript добавляет типизацию для надёжности кода, PostgreSQL — мощная реляционная база данных, Node.js позволяет использовать один язык (JavaScript) для frontend и backend, Prisma ORM упрощает работу с базой данных, Docker обеспечивает лёгкое развёртывание.»

### «Как реализована авторизация?»
> «Используется JWT (JSON Web Tokens) — при входе генерируются access и refresh токены. Access токен живёт 15 минут, refresh — 7 дней. При каждом запросе к API проверяются права доступа на основе роли пользователя.»

### «Как обнаруживаются конфликты в расписании?»
> «При создании или изменении занятия система проверяет, не занята ли аудитория в это время и не имеет ли преподаватель другое занятие в этот слот. Если конфликт найден — система выдаёт ошибку и не позволяет сохранить.»

### «Можно ли использовать систему без Docker?»
> «Да, можно установить PostgreSQL напрямую и запустить backend и frontend через npm run dev. Docker просто упрощает настройку — всё запускается одной командой.»

### «Сколько времени заняла разработка?»
> «Проект содержит более 15 000 строк кода в 92 файлах. Разработка велась поэтапно: сначала архитектура и база данных, затем backend API, потом frontend интерфейс, и наконец наполнение реальными данными СФЭК.»

### «Что бы вы добавили в будущем?»
> «Онлайн-развёртывание на сервере, мобильное приложение, интеграцию с электронным журналом, экспорт расписания в PDF и Excel, push-уведомления о изменениях в расписании, и функцию автоматического составления расписания с учётом ограничений.»

## ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК

| Проблема | Решение |
|----------|---------|
| Docker не запускается | Перезагрузите компьютер, запустите Docker Desktop заново |
| "Порт 5432 занят" | Запустите `ОСТАНОВКА_WINDOWS.bat`, затем снова `ЗАПУСК_WINDOWS.bat` |
| Страница не открывается | Подождите 30 сек, откройте http://localhost:5173 вручную |
| Данные не загружаются | Проверьте что backend запущен на http://localhost:3001 |
| "npm не найден" | Установите Node.js, перезагрузите компьютер |
| Всё зависло | Закройте все окна cmd, запустите `ОСТАНОВКА_WINDOWS.bat`, подождите 10 сек, запустите `ЗАПУСК_WINDOWS.bat` |
